# Дизайн-система DroneSim

Интерактивный макет: [`ui_mockup.html`](ui_mockup.html) (открыть через локальный сервер: `python -m http.server` в корне проекта → `http://127.0.0.1:8000/docs/design/ui_mockup.html`). Скриншоты: [`screens/`](screens/).

## Принципы
1. **Тёмный, спокойный, «приборный».** Интерфейс не спорит с картинкой полёта. Фон почти чёрный, панели — полупрозрачное «стекло» поверх 3D-сцены.
2. **Один акцент.** Лаймовый `#C8FF2E` — только для главного действия, активного выбора и «живых» индикаторов. Вторичный циан `#3DD9FF` — данные/телеметрия.
3. **Цифры — моноширинным шрифтом.** Всё, что меняется во времени (напряжение, скорость, таймеры, rates), — JetBrains Mono, чтобы не прыгало.
4. **Крупно и коротко.** Заголовки 28–76 px, жирность 800, отрицательный трекинг; подписи — 11–13 px капсом с разрядкой.
5. **Палец и клавиатура равноправны.** Цели ≥ 44 px, полная навигация стрелками/Enter/Esc и геймпадом (D-pad/A/B), фокус видим (обводка акцентом).

## Экраны
1. **Главное меню** — слева логотип, слоган, вертикальное меню (активный пункт подсвечен полосой акцента); справа карточка текущего дрона; по центру «испытание дня». Фон — живая 3D-сцена (ангар с дроном или пролёт камеры над картой). Статус-бар: подключённый пульт, FPS/частота физики, подсказки клавиш.
2. **Выбор карты** — сетка карточек 16:9 (превью, погода, сложность ★), фильтры-чипы; нижняя панель условий: время суток, ветер, погода → «Далее».
3. **Выбор дрона** — большая 3D-сцена (крутится, перетаскивается), карусель миниатюр, вкладки классов; справа спецификация: масса, TWR, скорость, время полёта, полосы характеристик, режимы полёта.
4. **Ангар** — настройка дрона: rates, PID-пресеты, уптилт, батарея, пропеллеры, экшн-камера вкл/выкл (масса/инерция меняются), окраска.
5. **Академия** — дорожка уроков с прогрессом и звёздами; заблокированные — приглушены.
6. **Настройки** — боковое меню разделов; «Управление» с живыми полосками каналов и кнопками калибровки/назначения тумблеров; «Rates» с графиком кривой (формулы Betaflight) и импортом CLI.
7. **Полёт** — FPV: OSD как в Betaflight (моно, белый с тенью, предупреждения мигают жёлтым), рыбий глаз и шум; GPS-дроны: аккуратный HUD с полупрозрачными плашками. Пауза — стекло поверх размытой сцены.
8. **Телефон** — два стика, ARM-слайдер сверху по центру, кнопки меню/режима/камеры/RTH по углам, минимальный OSD; всё внутри safe-area.
